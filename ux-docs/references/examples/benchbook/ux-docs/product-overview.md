# Product overview

Benchbook is an equipment scheduling tool for community workshops. It helps members share limited equipment and gives coordinators a way to plan servicing around members' needs.

## Core logic

Each item has a shared schedule for bookings and maintenance. Members book available time, and coordinators set time aside for servicing. Both activities affect when equipment is available to members.

## Key features

- [Equipment booking](equipment-booking/README.md) lets members reserve tools and reschedule disrupted bookings.
- [Maintenance](maintenance/README.md) lets coordinators schedule equipment servicing and see which bookings it affects.
