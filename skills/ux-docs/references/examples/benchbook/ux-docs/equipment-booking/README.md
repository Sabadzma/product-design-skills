# Equipment booking

Members reserve time with shared tools and can reschedule disrupted reservations. They choose a time from the item's availability, which reflects both member bookings and planned maintenance.

See [Book available equipment](decisions.md#book-available-equipment) and [Reschedule a disrupted reservation](decisions.md#reschedule-a-disrupted-reservation).

Review the [equipment booking scenarios](scenarios.md) when designing these flows.
