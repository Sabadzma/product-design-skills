# Glossary

**Equipment item** — An individual tool or machine with its own availability schedule.

**Maintenance block** — A period reserved for servicing an equipment item. See [Take equipment out of service](maintenance/decisions.md#take-equipment-out-of-service).

**Reservation** — A booking for a member to use an equipment item at a specific time. See [Book available equipment](equipment-booking/decisions.md#book-available-equipment).
